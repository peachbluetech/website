The best MCP servers for ad performance data in 2026 fall into three groups. Creative analytics servers (Peachblue, Motion, Atria, rule1, Foreplay) hand Claude data that is already analyzed: creatives grouped, scored, and tagged. The ad platforms' own servers (Meta, Amazon Ads, Google Ads) cost nothing to use but cover one platform each. Data connectors (Pipeboard, Windsor.ai, Supermetrics, Improvado) pipe raw rows from many platforms, and most of them can change your campaigns.

## What is an MCP server for ad data?

MCP (Model Context Protocol) is the open standard Claude, ChatGPT, and other AI assistants use to call outside tools. An ad data MCP server turns your ad accounts into tools the assistant can call, so you ask "which creatives drove last week's CPA spike" in chat instead of exporting a report. What the assistant can answer depends on what the server returns: raw platform rows, or data that has already been analyzed.

## How do you choose an ad data MCP server?

Four questions decide it:

1. **Which platforms?** The official servers cover one platform each. If you buy on Meta, Google Ads, and Amazon DSP, one connection or three is a real difference.
2. **Can it change campaigns?** Some servers only read; others pause ads, change budgets, and create campaigns. Decide how much an assistant should be allowed to do before you connect one.
3. **Raw rows or analysis?** Ask a raw-data server for your best creative and it ranks ads, so one video running in twelve ads looks like twelve mediocre ads. An analysis server groups the creative first.
4. **What does setup take?** Some need only a sign-in. Others need a developer token, an approved API app, or a local install.

## Official platform servers: one platform each

### 6. Meta Ads MCP: Meta's own, with writes

Meta opened its ads MCP server in beta on April 29, 2026, hosted at mcp.facebook.com/ads, and opened it to any developer with a Meta app on July 16. It reports performance with Meta's own diagnostics, benchmarks, and an opportunity score, and it can create and edit campaigns, ad sets, ads, and audiences. New ads start paused, your assistant asks before activating them, and business portfolio admins can block or cap actions per ad account. Meta lists no fee. Its documentation describes no tool that tags creative attributes or matches the same asset across uploads. More in [Claude for Meta ads creative analysis](/blog/claude-meta-ads-creative-analysis).

**Choose Meta Ads MCP if** you work on Meta only and want Claude to manage ads, not just read them.

### 7. Amazon Ads MCP: sponsored ads and DSP, for API teams

Amazon's server has been in open beta since February 2, 2026 and covers sponsored ads and Amazon DSP, with tools that create, update, and delete. It is not a sign-in-and-go route: you need an Amazon developer account and an approved Amazon Ads API app first. Endpoints are regional, and a Lite endpoint narrows it to three meta-tools. No fee is listed. Setup and limits are in our [Amazon Ads MCP in Claude](/blog/amazon-ads-mcp-claude) guide.

**Choose Amazon Ads MCP if** you have Ads API access and want Claude to act on Amazon accounts.

### 8. Google Ads MCP: open source and query-only

Google's open-source server (Apache-2.0, on GitHub) exposes three tools: a search that runs Google Ads queries, resource metadata, and the list of accounts you can reach. None of them changes a campaign. You run it yourself, locally or on your own cloud, with a Google Cloud project, OAuth credentials, and a developer token with at least Explorer access.

**Choose Google Ads MCP if** you are comfortable with the Google Ads API and want free, read-only query access.

**Pricing:** Starter $55 a month ($44 billed yearly), Growth $222 ($177), Enterprise on request. 14-day trial.

**Choose Supermetrics if** you already pipe marketing data into a warehouse and want the same sources in your assistant.

Improvado's MCP gives agents access to 187+ sources and "reads, writes, and monitors". The MCP Only plan includes 2 million rows a year, a daily sync, and 300 MCP actions a week; the full platform starts at $20,000 a year.

**Pricing:** MCP Only $100 a month.

**Choose Improvado if** you want an entry point into an enterprise data platform.

## Can an MCP server change your campaigns?

Several can. Meta's server creates ads paused and asks before activating them, and portfolio admins can block actions per ad account. Amazon's can create, update, and delete. Windsor's write functions, including pausing campaigns and adjusting budgets, are on every plan; Supermetrics creates campaigns paused; Pipeboard offers read-only tokens from Pro. Google's open-source server lists only query tools, and all 23 of Peachblue's tools are read-only. If an assistant will run on a schedule or for a team, start with read access and add writes deliberately.
